# Roadmap

## Phase 0 — Architecture
Domain language, ADRs, core journeys, ERD concept, UX architecture.

## Phase 1 — Foundation
Laravel/Vue/Flutter skeletons, tenancy, auth, RBAC, branch scopes, audit.

## Phase 2 — People + Structure
Organizations, branches, people, households, staff, catalog, resources.

## Phase 3 — Membership Core
Commercial products, membership plans, agreements, entitlements, ledger, cycles, add-ons.

## Phase 4 — Scheduling + Booking
Recurrence, sessions, staff assignments, booking windows, concurrency, waitlist, cancellation.

## Phase 5 — Three-pilot Core
Pole, swimming and gym configurations using the same domain model.

## Phase 6 — Payments + Portal + Mobile
Online gateway, member portal and first production Flutter flows.

## Phase 7 — Growth
CRM, communications, segmentation, automations, referrals.

## Phase 8 — Operations Expansion
POS, inventory, compensation, access hardware integrations.

## Phase 9 — Analytics
Aggregates, occupancy, profitability, demand signals.

## Phase 10 — Enterprise/Ecosystem
Public API, OAuth, white label, SSO, dedicated DB option.

## Phase 11 — Marketplace
Discovery, public inventory, purchases and commissions.
